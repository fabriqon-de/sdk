# Haus Blick

Haus Blick ist der eigenständige Home-Assistant-Bereich von PlantFrame. Seine Entwicklung liegt im [separaten Repository](https://github.com/plantframe-de/haus-blick).

Ziel ist eine räumliche Übersicht für Häuser, mit späterer Gerätezuordnung und Live-Zuständen. Diese Funktionen und eine gemeinsame SDK-Anbindung sind noch keine fertige Integration. Industrielle Architekturregeln werden nicht automatisch auf Wohnhäuser übertragen.

Haus Blick richtet sich an eine vorhandene Home-Assistant-Installation mit Add-on-Verwaltung. Der Landingpage-, Demo- und Dokumentationsserver startet weder Home Assistant noch einen Supervisor oder eine zusätzliche Haus-Blick-Anwendung.
